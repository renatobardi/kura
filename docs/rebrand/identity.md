# Kura — identidade visual (direção v1, aguardando aprovação)

Conceito: 蔵 (kura) = armazém. Washi (papel) como superfície, sumi (tinta) como texto,
um único acento shu (vermelhão de selo hanko) para ação. Visual limpo e espaçado.

## Tipografia
Geist (UI/display, peso máx 500, tracking -0.03em em títulos) · Geist Mono (código/ids) ·
Zen Kaku Gothic New apenas para kanji de marca (蔵). Substitui Inter/JetBrains Mono.

## Marca
Selo hanko quadrado (cantos 18%) com 蔵; wordmark "kura" minúsculo. Motivo seigaiha
apenas em onboarding/estados vazios, opacidade ≤ 8%. Sem gradientes, sem abelhas.
